# GridCraft لنظام Android

تطبيق جداول بيانات مفتوح المصدر بواجهة Kotlin وJetpack Compose ومحرك Rust.

## العربية

يمكن اختيار العربية أو الإنجليزية أو لغة النظام من إعدادات GridCraft ← اللغة.
يُحفظ الاختيار ويُطبّق مباشرة. في Android 13 والإصدارات الأحدث يتزامن أيضًا مع
إعدادات الهاتف ← التطبيقات ← GridCraft ← اللغة.

يشمل التعريب شاشة البداية والإعدادات، والقوائم وأدوات التحرير، والبحث عن الأوامر،
وتنسيق الخلايا والطباعة. تتجه واجهة التطبيق من اليمين إلى اليسار، وتبقى الصيغ
ومراجع الخلايا ولوحة الأرقام بترتيبها المعتاد. أسماء الملفات والأوراق وبيانات
المصنف وأسماء دوال Excel لا تُترجم. أوصاف الدوال الفنية وبعض رسائل المحرك
التفصيلية تظل بالإنجليزية.

## المحرك

حُدّث إلى الإصدار **0.12.1** مع الحفاظ على إضافات Android للأشكال والصور والمخططات.
تفاصيل المصدر والتوافق موجودة في [سجل مزامنة المحرك](ENGINE_UPSTREAM.md).

## أدوات المحرك في الواجهة

- **البيانات ← تحويل إلى رقم:** تحويل الأرقام المخزنة كنص ضمن التحديد، مع إمكانية التراجع.
- **الصيغ ← لصق الأسماء:** اختيار اسم معرّف في المصنف لإدراجه عند مؤشر الصيغة. يكتب زر «لصق القائمة» الأسماء ومراجعها في عمودين بدءًا من الخلية النشطة؛ وهو متاح عند عدم تحرير خلية.
- **عرض ← إظهار الكائنات / إظهار رموز التجميع:** التحكم بظهور الصور والأشكال والمخططات ورموز مجموعات الصفوف والأعمدة، مع الاحتفاظ بالبيانات نفسها.
- **البيانات ← إعدادات التجميع:** وضع صفوف الملخص أسفل التفاصيل أو أعلاها، وأعمدة الملخص إلى يمين التفاصيل أو يسارها، وتحديث مواضع أزرار التجميع وفقًا لذلك.
- **الجدول المحوري ← خيارات الجدول المحوري:** السماح بإظهار تفاصيل القيم أو تعطيله. يظهر تبويب الجدول المحوري عند تحديد خلية داخله؛ وزر «إظهار تفاصيل القيمة» ينشئ ورقة بالمصدر الداعم للقيمة المحددة، عندما تكون الخلية صالحة والتقرير محدثًا.

تتوفر الأوامر الجديدة أيضًا في البحث عن الأوامر بالعربية والإنجليزية.

## البناء

المتطلبات: JDK 17 أو أحدث، وAndroid SDK API 37، وNDK 29.0.14206865، وRust
المحدد في `rust-toolchain.toml`، و`cargo-ndk` الإصدار 4.1.2.

```sh
cargo install cargo-ndk --version 4.1.2 --locked
cd apps/gridcraft-android/android
./gradlew assembleDebug testDebugUnitTest
```

في Windows استخدم `gradlew.bat`. لبناء معمارية الهواتف فقط مرّر
`-Pgridcraft.abis=arm64-v8a`. ويمكن تحديد نسخة NDK أخرى مثبتة محليًا باستخدام
`-Pgridcraft.ndkVersion=<version>`.

تتوفر معلومات الوظائف والترخيص في [الملف الأصلي](README.md).
